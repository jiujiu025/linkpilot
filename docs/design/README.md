# LinkPilot Phase 0 架构设计文档

## 文档目的

本目录是基于 `docs/软路由产品设计方案.md` 的 Phase 0 架构设计和代码库审查结果。当前项目尚未进入 Phase 1 编码开发。本项目首款目标样机为小米 AX3000T，最低档参考 MT7981B 双核 1.3GHz、256MB 内存、128MB Flash、Wi-Fi 6、4 个千兆网口，但必须先确认具体硬件版本、OpenWrt 支持和恢复路径；N100/x86 仅作为后续性能对照平台。本目录中的内容用于设计评审、样机验证和后续任务拆解。

## 文档状态

- 阶段：Phase 0
- 状态：设计草案，等待用户确认后进入实现
- 代码状态：尚无业务代码、固件工程、Agent 工程或云端服务工程
- 验证状态：尚未连接真实硬件、真实线路和真实直播设备
- 安全边界：本文档不记录任何密码、UUID、私钥、订阅链接或线路凭证

## 使用约定

1. 原设计方案中的单 SSID、统一本地登录、客户/设备管理员分权、控制面与数据面分离、严格防泄露和失败回滚作为已确认方向。
2. PassWall 仅作为协议和历史配置来源，不作为核心业务模型或运行时依赖。
3. 所有线路凭证只能进入受保护的密钥管理和设备配置下发链路，不能进入普通日志、客户页面、测试样例或示例配置。
4. 任何性能、安全和稳定性指标都必须通过目标硬件、真实线路和真实设备实测；设计文档中的指标是验收门槛或测试方法，不是已达成结果。
5. 未经设计评审确认，不进入 Phase 1 编码开发。
