## 4. 资源预算与共存判断

| 能力 | 256MB/128MB 基线上的判断 | 当前结论 |
|---|---|---|
| 单 SSID、DHCP、基础防火墙 | 资源需求相对可控 | 条件可行，需实测无线驱动和隔离 |
| 本地门户 | 静态资源 + 轻量本地服务可行 | 条件可行，需控制依赖和日志 |
| sing-box | 精简配置、有限规则、单一活动核心 | 条件可行，吞吐和内存必须实测 |
| Xray | 不建议与 sing-box 同时常驻 | 互斥条件可行，需实测 |
| Router Agent | 轻量常驻进程 | 条件可行，需限制缓存和队列 |
| 本地探针 | 低频周期检查 | 条件可行，禁止默认高频测速 |
| DNS 防泄露 | 轻量 DNS + 防火墙接管 | 条件可行，规则/缓存需限量 |
| Kill Switch | nftables + policy routing | 条件可行，必须做故障实测 |
| 全部能力同时高负载运行 | 资源余量未知 | 当前不能确认通过 |

### 判断结论

256MB 内存和 128MB Flash 理论上可以承载基础版闭环，但不能采用双代理核心常驻、大型规则集、高频测速、详细流量日志和完整调试工具的组合。能否满足直播吞吐、温度、内存和恢复要求，必须由真实 AX3000T 验证。

## 5. 基础版功能裁剪

### 保留为必选

- 单 SSID、DHCP、客户端隔离和本地统一门户；
- 客户/设备管理员权限和无浏览器设备远程授权；
- 设备级 RouteProfile 绑定；
- sing-box 优先，首批验证 VLESS、Trojan、Shadowsocks、WireGuard；
- DNS 强制接管和缓存隔离；
- IPv6 默认关闭；
- nftables 默认拒绝和 Kill Switch；
- Router Agent 出站连接、配置签名、版本校验和回滚；
- 轻量本地探针、主备健康判断和审计摘要；
- 云端下发策略，设备本地继续转发和切线。

### 延后或限制

- Xray 与 sing-box 互斥运行，不同时常驻；
- Hysteria2、TUIC、NaiveProxy 待首批协议和性能通过后再加入；
- GeoIP/GeoSite 和自定义规则限制版本大小与条目数；
- 持续测速、DPI、逐包日志和复杂本地历史报表默认关闭；
- 多 WAN 物理聚合和高级 SD-WAN 不作为 AX3000T 基础版承诺；
- 双分区 OTA 必须先确认分区和恢复能力。

不得通过关闭 Kill Switch、DNS/IPv6 防泄露、设备隔离、签名校验、权限校验或回滚保护来适配资源限制。若核心闭环无法稳定运行，应调整设备角色，而不是降低安全边界。

## 6. 适配前置门槛

1. 实机身份、硬件版本和区域已确认。
2. 原厂固件只读备份完成，并通过大小、摘要和可读性检查。
3. 分区布局、启动方式和恢复入口已确认。
4. 无线芯片、网口映射、温度传感器和硬件卸载能力已确认。
5. 最小 OpenWrt 启动和有线/无线基础功能验证完成。
6. 资源基线、代理核心、门户峰值和探针负载已实测。
7. DNS、IPv6、Kill Switch 和未授权设备隔离通过真实测试。
