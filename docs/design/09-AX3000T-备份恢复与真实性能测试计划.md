# AX3000T 备份、恢复与真实性能测试计划

## 1. 安全原则

本计划是测试设计，不授权刷机、恢复出厂、擦除分区、修改启动参数或覆盖固件。涉及设备写入的步骤，必须在硬件身份和恢复路径经评审确认后单独批准。

测试记录不得包含密码、UUID、私钥、完整订阅链接、完整线路地址或其他线路凭证。

## 2. 原厂固件备份

### A. 外观和身份

- 记录底部铭牌、完整型号、区域、硬件版本和原厂固件版本。
- 序列号只保留脱敏摘要；记录 WAN/LAN 标识、恢复按键和指示灯行为。
- 不拆机、不改配置、不执行恢复出厂。

### B. 只读识别

- 在不改变设备状态的前提下确认 CPU、内存、无线芯片、交换芯片和温度接口。
- 读取分区信息前确认方法不会写入设备。
- 保存识别输出、时间和工具版本，并清理敏感信息。

### C. 备份和校验

- 优先使用官方升级包、恢复包或只读导出方式。
- 如需串口或其他维护接口，先完成不会改变启动状态的风险评审。
- 备份文件使用访问控制和至少两份校验摘要保存。
- 只做离线完整性检查，不尝试写回设备。

### 备份验收

- 备份文件完整可读，大小和摘要已记录。
- 分区与备份文件的对应关系已建立。
- 恢复介质、恢复入口和适用固件版本已确认。
- 未执行写回、恢复出厂或固件替换。

## 3. 恢复、救砖和升级验证

恢复验证必须建立在原厂备份和可用恢复路径之上。恢复路径未知时，先暂停写入测试。

计划顺序：

1. 确认官方恢复流程、版本限制和硬件适用范围。
2. 准备隔离的测试网络、稳定电源和日志采集路径。
3. 设计成功启动、网络恢复、无线恢复、配置状态和再次升级观察项。
4. 首次写入前确认原厂备份、恢复介质和停止条件均可用。
5. 仅在另行批准后执行最小范围升级验证，不进行盲目循环写入。
6. 记录启动日志、指示灯、恢复耗时和最终网络状态。

### 必测升级场景

- 正常升级并成功启动；
- 签名错误、摘要错误或不兼容硬件版本的包被拒绝；
- 版本降级按策略阻止；
- 升级中断电后的启动和恢复；
- 配置、设备身份和审计状态迁移；
- 代理配置失败后的本地回滚；
- 云端不可用时当前稳定配置继续运行。

### 救砖验收

- 原厂固件可恢复启动。
- 恢复后 WAN、LAN、Wi-Fi 和管理入口可用。
- 恢复不依赖未记录的外部服务。
- 失败有明确停止条件，不进行破坏性重试。

## 4. 真实直播和代理测试

### 测试条件

记录 AX3000T 完整型号/硬件版本、固件版本、温度环境、电源、散热、有线或无线接入、客户端数量、设备类型、直播码率、协议类别、地区标签、执行器版本、规则版本、探针策略版本和异常事件。不得记录敏感凭证。

### 测试顺序

1. 单 SSID、DHCP、门户引导和客户登录。
2. 无浏览器设备进入待授权区，由门户完成远程授权。
3. 绑定 RouteProfile，验证出口、DNS 和目标业务访问。
4. 验证严格全局代理、白名单、默认阻断和大陆直连/其他代理。
5. 停止代理核心或使线路不可用，确认 Kill Switch 阻断普通 WAN 直连。
6. 恢复线路，验证备用线路、新连接切换和审计记录。
7. 断开云端控制通道，验证本地转发、DNS、门户和自动切线继续工作。

### 直播覆盖

- 首先使用有线编码器或摄像机测试长连接上传，再测试 Wi-Fi 6 客户端。
- 分别覆盖 TCP、UDP、QUIC 和长连接业务。
- 覆盖单设备、多设备并发、上下行混合和探针并行运行。
- 测试主线路断开、短时抖动、备用线路故障和恢复。
- 分别记录新连接恢复时间与已有直播连接中断情况，不能用出口 IP 变化代替业务恢复。

## 5. 资源、温度和稳定性

采集 CPU 每核心利用率、频率和降频、内存峰值/OOM、Flash 可用空间和日志增长、SoC/无线/外壳温度、吞吐、丢包、重传、延迟、抖动、连接数，以及代理、Agent、门户、DNS 和探针进程资源。

测试组合：

1. 基础网络空载；
2. 单 SSID + 门户 + DNS + Kill Switch；
3. 增加单一代理核心和单线路；
4. 增加 Agent 和低频探针；
5. 增加直播设备持续上传；
6. 增加主备健康检查和故障切换；
7. 重复冷启动、热重启和云端断线恢复。

任一步骤出现 OOM、代理崩溃、无线重启、异常降频、未授权直连、规则失效或不可解释的重启，均判为该组合未通过。

## 6. 防泄露和稳定性通过条件

- 客户端 UDP/TCP 53 无法绕过受控 DNS；DoT、DoH 和硬编码 DNS 按策略处理。
- IPv6 地址、IPv6 DNS、RA 和 DHCPv6 不产生未受控公网路径。
- 代理核心停止、配置损坏、线路全部失败时普通 WAN 直连被阻断。
- 未授权设备只能访问门户和必要局域网协议；客户设备不能横向访问。
- 云端断线不导致策略回退为全部直连。
- 日志、诊断包、状态上报和门户响应不包含线路凭证。
- 最低连续稳定性为 72 小时，关键版本建议 168 小时。
- 测试期间不得出现未解释的重启、OOM、防泄露失败或频繁切线。
- 未完成指标以“未验证”记录，不填写推测值或伪造成功结论。
